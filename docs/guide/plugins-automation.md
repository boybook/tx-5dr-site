# 插件与自动化

插件可以改变候选台排序、自动起呼、通联流程、日志同步和界面面板。普通用户可以直接使用内置插件和插件市场。

## 插件分成两类

### 通联机制

通联机制决定一个操作员如何完成正式 FT8 或实验性 FT4 的消息交换。同一操作员同一时间只能选择一个：

- **Standard QSO**：默认的 TX1-TX6 标准通联
- **Assisted QSO Queue**：由操作员选择队列目标，策略负责逐项完成，可配置并行流
- **WW Digi**：面向 WW Digi 竞赛交换、计分和工作台

切换通联机制会改变操作员卡片上的状态和可用操作。正在通联时不要切换，先停止发射并确认当前 QSO 是否已经写入日志。

### 工具插件

工具插件可以多个同时启用。内置能力包括：

- 按 SNR 或呼号规则过滤候选台
- 根据已通联记录调整优先级
- 记住长期无回应的目标并降低优先级
- 守候指定呼号、Grid、新 DXCC、新 Grid 或新呼号
- 按计划自动 CQ 或切换波段
- 自动选择较空闲的发射音频频率
- 同步 WaveLog、QRZ、LoTW 和 Club Log
- 广播 WSJT-X 兼容 UDP 数据

工具插件的组合可能互相影响。一次只新增一个自动起呼或过滤插件，观察几个周期后再继续组合。

## 管理已安装插件

进入 **设置 > 插件 > 已安装**：

1. 选择插件并查看其类型、权限和状态。
2. 启用或禁用全局插件。
3. 填写全局设置并保存。
4. 需要操作员设置时，进入 **设置 > 操作员**，在对应操作员下配置。
5. 回到插件页查看运行日志，确认没有加载或权限错误。

策略插件被全局启用后，仍需要分配给具体操作员；工具插件也可能要求操作员级参数。

## 使用插件市场

进入 **设置 > 插件 > 市场**：

1. 搜索或按分类浏览插件。
2. 查看作者、版本、最低 Host 版本、许可证和权限。
3. 阅读 README 和风险提示。
4. 安装后回到“已安装”，检查配置再启用。
5. 更新插件时重新核对权限变化。

![插件市场，标出搜索和版本通道，以及插件来源、权限和风险信息](/guide/screenshots/annotated/plugin-marketplace.png)

*安装前检查版本通道、最低 Host 版本、来源、权限和风险提示。*

市场安装的插件会在本机 TX-5DR 进程中运行。即使页面显示“没有敏感权限”，也应确认来源、作者和更新内容。

## 手工安装

插件页会显示当前运行形态的真实插件目录。将完整插件目录放入后，点击 **重载插件**。

手工插件必须是已经构建好的可运行 JavaScript，不能直接放 TypeScript 源码。入口文件应使用插件系统支持的文件名；加载失败时在 **插件运行日志** 中查看明确原因。

::: danger 本地代码权限
手工放入插件目录的代码由 TX-5DR 运行。只安装可信来源，或先完成代码审查。
:::

## 自动化的安全边界

- “已启用”不一定表示插件能发射；自动起呼状态会单独显示在操作员卡片
- 多个自动起呼插件由 Host 统一仲裁，不应各自绕过 PTT 控制
- 过滤器可能让你看得到解码却不会自动选择该电台
- 标准频率、并行通联和多操作员有额外防冲突限制
- 暂停自动起呼不等于停止已经开始的物理发射
- 紧急情况使用 **立即停止发射**

## 排查插件问题

1. 确认插件在“已安装”列表中且版本满足当前 TX-5DR。
2. 查看是全局设置还是操作员设置未完成。
3. 打开插件运行日志，筛选插件名和错误级别。
4. 暂时禁用最近增加的其他自动化插件，排除组合影响。
5. 市场安装失败时检查网络、磁盘空间和 Host 版本。
6. 手工插件加载失败时检查入口文件、导出格式和依赖打包。

开发自定义插件时再进入独立的 [插件 API 文档](../plugin-api/)。
