# 设置索引

主界面右上角的齿轮按钮打开设置。不同角色看到的页签不同：管理员可以修改系统和硬件相关设置，操作员只能修改被授权的操作员与个人偏好，观察者以查看为主。

电台连接和音频设备不在普通设置页中修改。请点击底部电台控制区的电台配置按钮，进入 [电台 Profile](./radio-profile)。

## 保存方式

- 页脚出现 **保存设置** 时，修改后需要显式保存
- 插件市场的安装、更新和卸载会立即执行
- Profile 的创建、切换和连接使用自己的确认按钮
- 关闭设置前若提示未保存，请选择保存、放弃或返回继续检查

## 操作员

用于：

- 新建、修改和删除操作员
- 设置呼号、Grid 和并行通联流数
- 选择每个操作员的通联机制
- 配置操作员级插件和自动化偏好
- 控制当前浏览器显示哪些操作员

操作员不是登录账号。给其他人授权请使用“用户管理”。

## 显示与通知

用于调整解码消息的显示方式：

- CQ、我的呼号、新呼号、新 DXCC、新 Grid 的高亮
- 表格显示偏好和颜色
- QSO 完成等浏览器通知
- 通知权限和本地提示

通知权限由浏览器或 Android 系统最终决定。页面开关开启但系统权限被拒绝时，仍然不会出现通知。

## 系统设置

系统设置包含多组管理员能力。

### 远程访问

选择仅本机、局域网或公网，配置公开观察、允许地址、连接数和超时。详见 [操作员、用户与远程访问](./operators-remote)。

### 实时音频

选择自动或兼容传输，配置公网 UDP 候选并查看音频链路状态。详见 [远程监听与语音链路](./realtime-audio)。

### 时钟与 NTP

- 查看测得的时钟偏差
- 手动测量或应用偏差
- 启用自动 NTP 校正
- 管理多个 NTP 服务器和优先级

FT8 首次使用优先修正操作系统时钟，不要随意设置较大的手动偏移。

### 解码和性能

- 选择 FT8 解码窗口强度
- 为实验性 FT4 选择解码窗口
- 决定发射期间是否继续频谱或解码
- 限制相同报文连续发射次数
- 查看服务器健康和解码工作线程
- 在管理员诊断中采集 CPU Profile

解码窗口越多，弱信号机会可能增加，但 CPU 使用也会上升。低功耗主机应先使用默认或轻量设置。

### PSK Reporter

启用解码上报，设置接收台呼号与 Grid，并查看待发送和最近上报状态。详见 [外部集成](./integrations#psk-reporter)。

### 日志级别

查看日志目录并选择 error、warn、info 或 debug。日常保持默认；只在复现问题期间临时使用 debug。

### 桌面 HTTPS 与更新

桌面版可以管理本机/LAN HTTPS、自签名或导入证书，并在“关于”页检查应用更新。Linux、Docker 和 Android 的入口由各自运行环境管理。

### 匿名遥测

遥测需要明确同意。界面会列出收集范围和明确不收集的内容；手动提交诊断是另一个独立操作。

## 帮助改进

用于选择日志来源和时间范围并上传诊断。提交前记录问题时间、版本和复现步骤，提交后保留反馈 ID。

详见 [日常维护](./maintenance#提交诊断)。

## Rigctld 桥接

向 N1MM、WSJT-X、JTDX、fldigi 等软件开放 Hamlib NET rigctl 兼容端口。默认只读；允许写入时外部软件可能切频、改模式或 PTT。

详见 [外部集成](./integrations#向-wsjt-x、jtdx、n1mm-或-fldigi-提供电台控制)。

## 频率预设

用于维护正式的 FT8/语音，以及实验性 FT4、CW、SSTV、FAX 的频率入口：

- 新建、编辑、删除和排序预设
- 设置波段、频率、通联模式和电台模式
- FM 预设可设置中继方向、偏移、CTCSS 或 DCS
- 恢复系统默认预设

切换预设可能同时写入电台频率、模式、中继偏移和亚音。第一次使用自定义预设时应观察电台实际状态。

## 用户管理

用于创建观察者、操作员和管理员账号，分配操作员、有效期、频段与具体权限，并分享或撤销令牌。

详见 [操作员、用户与远程访问](./operators-remote#创建给其他人的访问方式)。

## 电台信息

记录共享站台的：

- 名称和站台呼号
- Grid、QTH、经纬度
- 天线、功率或其他 Markdown 说明

电台信息用于站点展示和位置计算。实际发报身份仍以当前操作员为准。

## OpenWebRX

添加远端 SDR 站点、测试连接、选择 Profile、试听和调谐。详见 [外部集成](./integrations#openwebrx-辅助接收)。

## 插件

管理已安装插件、市场、全局设置、目录、权限和运行日志。操作员级插件设置仍在“操作员”页。

详见 [插件与自动化](./plugins-automation)。

## 快捷键

可以为常用动作分配键盘快捷键，例如：

- 选择操作员
- 开始或停止发射
- 切换 TX1 至 TX6
- 重置到 CQ
- 语音 PTT
- CW 预设报文

分配前检查是否与浏览器、操作系统或日志输入框冲突。远程操作时不要把容易误触的普通字母键绑定到 PTT。

## 关于

显示 TX-5DR 版本、commit、构建时间、许可证和依赖信息。桌面管理员还可以从这里检查、下载并安装更新。
