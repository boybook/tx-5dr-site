# 在 Android 设备上运行完整 TX-5DR

TX-5DR Android 可以把手机、平板或 Android TV 变成电台旁的独立运行主机。它会在设备内安装完整 TX-5DR runtime，通过 USB 音频和 USB 串口连接电台，并提供两种操作入口：

- 直接在应用内置 WebView 中使用 TX-5DR
- 从同一 Wi-Fi 或手机热点内的电脑、平板、手机浏览器访问

它不是只能遥控另一台 TX-5DR 的客户端。只要 Android 设备保持服务运行并连接电台，另一台操作终端就无需远程桌面。

## 设备要求

- Android 9 或更高版本
- 64 位 Android 用户空间，ABI 为 `arm64-v8a`
- 安装 APK 和完整运行环境所需的可用存储空间
- 首次安装运行环境时可访问互联网
- USB 连接电台时，设备需要 USB Host/OTG 能力和合适的 OTG、供电及转接方案

::: warning 不要只看处理器型号
部分 Android TV 和盒子使用 ARMv8 处理器，却运行 32 位 Android（`armeabi-v7a` 或 `zygote32`）。这种设备不能运行当前 arm64 TX-5DR runtime。应用会在不兼容设备上显示“不支持此 Android 系统”。
:::

## 1. 安装 APK

从 [Android nightly 发布页](https://github.com/boybook/tx5dr-android-bridge/releases/tag/nightly-android-bridge)下载 arm64 APK。当前版本不是 Play Store 正式版，需要按 Android 提示允许当前浏览器或文件管理器“安装未知应用”。

nightly APK 已签名，可直接安装和覆盖更新，但仍属于现场测试版本。不要从不明镜像下载重新签名的 APK。

## 2. 安装 TX-5DR 引擎

首次打开应用时：

1. 点击“安装引擎”。
2. 确认下载 Android arm64 运行环境。
3. 等待应用完成下载、大小检查、SHA-256 校验和解压。
4. 出现“引擎安装成功”后，点击“启动服务”。
5. 状态变为“可以开始使用”后，点击“进入 TX-5DR”。

应用内置 WebView 会打开本机 `127.0.0.1` 入口，并使用一次性登录流程进入 TX-5DR。运行环境更新失败时，应用不会用未完成的下载覆盖当前可用版本。

## 3. 连接 USB 音频和串口

### USB 音频

1. 用 OTG 或带供电的 USB Hub 把电台 USB 音频设备接到 Android。
2. Android 弹出 USB 设备授权时，允许 TX-5DR 使用该设备。
3. 在 Android 状态页查看“USB 音频”，确认出现输入和输出设备。
4. 进入 TX-5DR，在 Profile 的音频设置中选择对应的 Android 输入与输出。
5. 接收时确认输入电平变化；发射前先把电台功率和音频增益调低。

Android 要求音频输入应用持有麦克风权限，因此即使输入来自 USB 电台，仍可能出现 `RECORD_AUDIO` 授权提示。拒绝后服务可以继续运行，但无法把电台输入送入 TX-5DR。只使用音频输出时不需要该权限。

### USB 串口与 Hamlib

1. 接入电台 CAT 串口并允许 USB 授权。
2. 状态页的“USB 串口”应显示已映射设备。
3. 在 TX-5DR Profile 中选择 Hamlib 和电台型号。
4. 串口路径选择 Android 提供的路径，第一台通常为 `/opt/tx5dr-data/android-dev/ttyUSB0`；多台设备按状态页显示的实际路径选择。
5. 设置电台要求的波特率、数据位、停止位和校验方式，先测试 CAT，再测试 PTT。

当前 USB 串口桥接中的 CAT 数据和常见串口参数同步已经实现，DTR/RTS/CW 控制线仍属于实验能力。如果 PTT 方式可选，优先使用 CAT PTT，并在实机上验证后再值守使用。

通过网络 Hamlib、ICOM WLAN 或 TCI 连接时，不需要 USB 串口桥接，但 Android 设备必须能够访问电台的 IP 和端口。

## 4. 从另一台设备访问

服务健康后，Android 状态页会显示“热点/局域网入口”和管理员 Token。默认 Web 端口为 `8076`。

### 同一 Wi-Fi

1. 让 Android 运行主机和操作终端连接同一个局域网。
2. 在操作终端浏览器打开状态页显示的 LAN 地址。
3. 使用状态页显示的管理员 Token，或已创建的操作员令牌登录。

### 手机热点

1. 在 Android 设备上开启热点。
2. 让笔记本、平板或另一台手机连接该热点。
3. 点击 Android 状态页的“刷新 LAN”。
4. 在操作终端打开新显示的热点地址并登录。

LAN 地址不会包含管理员 Token。只有内置 WebView 使用本机一次性登录流程；外部浏览器必须正常登录。不要把 Token 发给不需要控制电台的人。

如果地址无法访问，检查 Wi-Fi AP 隔离、热点客户端隔离、VPN 路由和厂商后台限制。蜂窝网络分配的地址通常不能直接作为入站访问地址。

## 5. 设置长时间运行

- 开启“值守模式”，让服务在息屏时保持前台运行。
- 按应用入口检查电池优化设置，避免系统过早停止后台服务。
- 允许通知后，TX-5DR 的 QSO 与系统提醒才能显示为 Android 通知。
- 长时间运行前准备稳定供电；同时使用 OTG 和充电时，需要支持相应模式的 Hub 或转接器。
- Android 厂商的省电策略不同。首次值守应观察数小时，确认息屏、网络切换和 USB 重连后的实际行为。

## 音频与发射安全

Android 只能使用系统实际报告的输入和输出方向。耳机口只报告输出时，应用不能把它强制变成输入。

3.5 mm CTIA 麦克风触点通常是带偏置的麦克风电平，并不是电台线路输入。连接电台前可能需要正确的转接、衰减、直流隔离和电气隔离。使用 Android 模拟音频输出发射时，开启“勿扰”，避免系统提示音进入电台发射链路。

拔出设备、路由改变或音频焦点丢失时，桥接会停止受影响的音频流，而不是假定新的系统默认设备仍然安全。恢复后仍应重新确认 TX-5DR 中的实际输入和输出选择。

## 更新 Android 版

Android 有两个独立更新对象：

1. **APK**：从 Android nightly 发布页下载新 APK 并覆盖安装。
2. **TX-5DR 引擎**：打开“诊断与设置 > 安装/更新”。

更新前结束发射，并从“诊断与设置 > 数据目录”备份用户数据、日志、插件和插件数据。更新后重新确认 USB 授权、音频路由、Hamlib 串口路径和低功率 PTT。

## 当前限制

- 仅支持真实的 Android 9+ arm64 设备，不支持 32 位 Android 用户空间。
- 尚无 Play Store、AAB 或 stable 发布通道。
- APK 不会自行安装更新；TX-5DR 引擎可在应用内单独更新。
- DTR/RTS/CW 串口控制线仍需要更多电台实机验证。
- 不同厂商的 USB、音频 HAL、热点和后台限制差异很大，不能仅凭设备规格表判断全部能力。
- 局域网浏览器必须能实际路由到 Android 设备；AP 隔离、VPN 或运营商网络可能阻止连接。
