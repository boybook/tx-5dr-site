# 数值表与电台控制

连接电台后，TX-5DR 会把频率、PTT、接收/发射数值表和电台参数集中到同一网页。远程使用者可以直接操作真实站台，不必打开远程桌面去寻找电台厂商软件里的旋钮。

## 两个入口，不要混淆

主界面左上电台名称旁有两个按钮：

- 滑杆按钮 **电台控制**：调整当前电台实际报告支持的参数；
- 齿轮按钮 **电台配置**：管理 Profile、连接方式、PTT 和音频设备。

电台已连接时，也可以直接点击电台名称打开 **电台控制**。频率和工作模式位于主控制栏，不需要进入参数面板。

![电台控制面板，左侧为天馈射频音频控制，右侧为模式和频率控制](/guide/screenshots/annotated/radio-controls.png)

*控制项按用途分组；当前电台不支持或暂时不可用的项目会禁用或收起。*

## 67 项控制不是每台电台都有 67 项

当前 TX-5DR 能识别并整合 67 项电台控制。连接建立后，系统会根据 Hamlib、ICOM WLAN 或 TCI 后端的声明和实际读写结果决定哪些项目可用：

- 已确认支持的项目直接显示；
- 当前电台不支持的项目收在 **当前电台不支持的功能** 中；
- 暂时不能操作时会显示“电台正忙”“当前模式下不可用”或“电台报告此控制当前不可用”；
- 点击标题旁的 **刷新电台参数**可重新探测和读取。

这 67 项按界面分成五组，用户看到的是含义明确的名称，而不是 Hamlib 内部参数：

| 界面分组 | 覆盖的控制能力 |
| --- | --- |
| **天馈** | 自动天调、手动调谐 |
| **射频** | 发射功率、RF 增益、前置放大、衰减器、AGC 速度与 AGC 时间；噪声消隐及强度、数字降噪及强度、APF 及强度；IF Shift、PBT 内侧/外侧、自动陷波、手动陷波开关与位置；Drive 增益、Digi-SEL 及电平；频谱输出、保持、速度、参考电平、平均、VBW、RBW、发射时频谱和频谱中心 |
| **音频** | AF 增益、静噪、MIC 增益、语音压缩与压缩强度、监听开关与监听增益、VOX 开关/增益/Anti-VOX/延时、音频平衡、Audio IF |
| **操作** | 电台模式、模式频宽、Split、VFO、RIT/XIT 开关与偏移、调谐步进；CW 音调、键速、Break-In 模式与延时；中继方向与偏移、亚音发射、亚音静噪、CTCSS 亚音、DCS 码 |
| **系统** | 面板锁定、静音、按键提示音 |

表中每个中文名称对应一个独立控制，共 67 项。部分项目会合并成一张卡片，例如“自动天调 + 手动调谐”“语音压缩 + 压缩强度”“VOX + 增益/Anti-VOX/延时”，便于按一个功能整体操作。

::: tip “不支持”说的是当前控制链路
项目被放进“不支持”区域，不一定代表电台面板上没有这个功能。它表示当前型号、固件或连接后端没有向 TX-5DR 提供可靠的读写接口。此时可以在电台本机操作，但不要假定网页状态会同步。
:::

## 怎样操作控制项

面板会根据参数类型选择合适控件：

- 开关项直接切换，例如 NB、VOX、Split；
- 连续数值使用滑块，例如 RF 增益、MIC 增益；
- 固定档位使用菜单，例如前置放大、AGC 速度、VFO；
- 纯动作使用按钮，例如手动调谐；
- 只读项只显示当前状态，例如某些连接上的电台模式。

写入后等待电台回读，不要连续快速拖动多个参数。电台忙于 PTT、调谐或模式切换时，部分项目会暂时禁用；等回到 RX 后再刷新。

### 发射功率的两种刻度

**发射功率**默认以百分比显示。如果 Hamlib 对该电台报告了离散功率档位，可以在百分比和 **Hamlib** 档位之间切换。百分比表示电台额定功率范围内的位置，不等于已经测得的瓦数；真实 RF 输出要看 Power 表或外接功率计。

### 电源控制是独立能力

电台开关机可能导致连接本身消失，因此它不属于上述 67 个普通参数。支持的 Profile 会在 Profile 列表或电台控制标题旁显示电源按钮；没有出现时，不代表可以通过其他开关强行关机。

### 天调有两个不同动作

工具栏的塔形按钮 **天调控制**包含：

- **电台内置天调**：打开自动天调，或调用电台报告的手动调谐能力；
- **外接天调 → 手动单音调谐**：TX-5DR 持续发射短音，供外接天调或站台测试使用，必须再次点击才能停止。

执行任一种调谐前都要连接正确天线、降低功率并确认频率空闲。单音调谐不是无 RF 的测试模式。

## 读懂四个数值表

数值表位于主界面下方，只显示当前连接实际提供的项目。接收时第一格显示 **Level**，PTT 生效后切换为 **Power**；SWR 和 ALC 主要在发射期间更新。

| 数值表 | 能做什么 | 正确用法 | 边界 |
| --- | --- | --- | --- |
| **Level** | 查看接收信号强度 | 观察噪声底和信号变化，辅助判断前置放大、衰减和 RF 增益 | 依电台可显示 S 值、相对 S9 的 dB，并在空间足够时显示换算 dBm；不是校准场强仪 |
| **Power** | 查看发射输出 | 低功率测试时确认确实有 RF 输出 | 可能显示百分比、瓦数，或“当前瓦数/最大瓦数”；数据来源和精度由电台决定 |
| **SWR** | 观察天馈匹配 | 换频段、天线或调谐后检查，异常时立即停发 | 只在后端提供 SWR 时出现，不能替代独立驻波表和天线安全检查 |
| **ALC** | 判断 TX 音频是否可能过驱 | 调整 **发射音量增益**，让发射保持在线性范围 | 各厂商标度不同；没有读数不代表没有 ALC |

发射停止后，最后读数会短暂保留，便于看清结果；数据超时后显示 `--`。不要把保留值误认为电台仍在发射，PTT 状态和电台 TX 指示才是主要依据。

## ALC 告警怎样处理

当后端报告 ALC 达到告警区，TX-5DR 会把仪表标红并弹出 **ALC 过高**。部分数字音频链路使用 dBFS，达到 -3 dBFS 警戒区也会提示。

处理顺序：

1. 立即降低工具栏中的 **发射音量增益**；
2. 必要时停止 PTT，再检查 Profile 的输出设备和电台 DATA/MOD 输入；
3. 重新以低功率、短时单音测试；
4. 按电台说明书确认该型号允许的 ALC 区间。

降低 RF 发射功率不会修复已经削顶的音频。反过来，提高 MIC 增益也不是提升 FT8 输出的通用方法，因为很多电台的数据输入不经过话筒增益。

ALC 浮窗可以选择“本会话不再自动弹出”，但数值告警仍保留，刷新网页后自动提示会恢复。只应在已经用电台仪表或外接设备确认标度特殊时临时抑制。

## 三组看起来相似、实际不同的音量

| 控件 | 调整哪里 | 不会调整哪里 |
| --- | --- | --- |
| **AF 增益** | 电台本机扬声器/耳机输出 | 浏览器音频监听音量 |
| **MIC 增益** | 电台话筒输入前级，主要用于语音 | TX-5DR 的 FT8 数字音频输出 |
| **发射音量增益** | TX-5DR 送往当前 Profile 输出设备的总增益 | 电台 RF 功率上限 |
| **音频监听音量** | 当前浏览器播放的 RX 监听声音 | 服务端解码电平和电台 AF 增益 |
| **监听增益/监听开关** | 电台自身的发射监听 MON 功能 | 浏览器的远程监听开关 |

远程站台调节前先确认自己操作的是哪一层。最常见的错误是把浏览器监听音量当作接收增益，或用 RF 功率掩盖 TX 音频过驱。

## 不同工作方式的建议

### FT8（正式）

- 数字解码通常关闭静噪，少用会改变波形的 NR、NB 和音频滤波；
- 从低 RF 功率和低发射音量增益开始，用 Power/SWR/ALC 联合判断；
- 电台模式通常使用 USB 或 USB-DATA，但 DATA 音频来源仍按电台说明书设置；
- FT4 当前属于实验功能，即使复用相同控制也要单独验证时序和发射。

### 语音（正式）

- 根据话筒调整 MIC 增益和语音压缩，避免只追求更大的 ALC 或平均功率；
- AF 增益、静噪、NR、NB、AGC、滤波频宽可按听感和干扰情况调整；
- 使用 VOX 时逐步校准 VOX 增益、Anti-VOX 和延时，先确认不会被远程回放误触发。

### CW、SSTV、FAX（实验）

这些模式当前按实验功能处理。即使电台控制面板显示 CW 音调、键速或 Break-In，也只说明控制接口可见，不代表整套实验模式已在该电台上完成验证。发射前应单独检查接线、占空比和释放 PTT 的行为。

## 远程操作的安全习惯

- 给不同用户分配最小必要权限；查看者不应获得电台参数写入权限；
- 在站台信息或 Profile 描述中注明天线覆盖频段和最大允许功率；
- 改频、切模式、调天调和改功率前确认没有其他操作员正在发射；
- 每次只改一项，等待回读后再继续；
- 看到“电台正忙”时先查 PTT、调谐或其他操作员，不要反复点击；
- 网页状态与电台面板不一致时，以立即停止发射和现场安全为先，再使用 **刷新电台参数**或重新连接 Profile。
