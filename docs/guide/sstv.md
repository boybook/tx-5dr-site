# SSTV（实验）

::: warning 实验功能
SSTV 收发、模板和历史格式仍可能调整。图片发射持续时间较长，首次测试请使用低功率或假负载，并全程观察电台散热、SWR 和 ALC。
:::

TX-5DR 可以自动识别并接收 SSTV，也可以在网页中制作图片、发送、保存模板和管理收发历史。SSTV 工作区还保留语音 PTT 和专用 QSO 表单，便于先语音协调再传图。

## 能做什么

- 自动通过 VIS/同步识别接收模式，或手工指定模式接收。
- 在连续纸带上显示接收内容，并保存当前纸带。
- 支持 Robot、Martin、Scottie、PD、Wraase、Pasokon 和黑白系列；当前运行时提供 31 种模式，以下拉框实际列表为准。
- 上传 PNG、JPEG、WebP 背景，选择填充/适应。
- 添加多个文字图层，移动、缩放、旋转，并设置字号、颜色、描边和对齐。
- 使用变量生成呼号、Grid、RSV、UTC、频率和备注。
- 保存个人模板，发送增强校准前导和 FSK/CW 台呼识别。
- 查看接收/发送历史，打开、下载、重发自己的已发送图片或删除记录。

![SSTV 工作区，左侧显示接收图像，右侧显示发送编辑器和发射控制](/guide/screenshots/original/sstv-main.png)

*SSTV 工作区同时显示接收纸带、图片编辑器、发送进度、语音 PTT 和 QSO 日志。*

## 发射前检查

1. Profile 的接收和发射音频设备正确，电台 PTT 已验证。
2. 已选择带呼号的操作员；需要台呼识别时，呼号必须能被当前编码方式接受。
3. 电台模式和侧带与所选频率一致。HF 常用 USB/LSB，VHF ISS SSTV 常用 FM，以实际活动和当地规划为准。
4. 打开底部 **引擎**，先确认接收纸带和频谱有数据。
5. 使用适合高占空比的功率，关闭不必要的语音压缩和处理。

## 接收 SSTV

1. 在底部工作模式选择 **SSTV**。
2. 从左侧频率列表选择当地活动频率或 ISS 预设，并确认 USB、LSB 或 FM。
3. 打开 **引擎**。
4. 接收画面右上角保持 **自动**。收到有效 VIS 和同步后，纸带会显示模式名称并逐行出图。
5. 如果错过 VIS、已知对方模式，或自动识别不稳定，从接收模式下拉框手工选 Robot/Martin/Scottie 等具体模式。

接收是连续纸带：一次传输结束后不会清空整个视图，新的协议边界会继续向下写。向上翻看旧内容时，自动跟随会暂停；点击右下角按钮回到最新行。

点击纸带左上角的保存图标，可把当前接收内容保存到历史。完整协议捕获也会形成接收记录；历史中的黄色提示表示部分接收或纸带被截断。

## 制作发送图片

1. 切到右侧 **发送**。
2. 选择一个模板，或从空白画布开始。
3. 点击 **背景** 上传 PNG、JPEG 或 WebP。
4. 选择 **填充** 裁切铺满，或 **适应** 完整显示并留边。
5. 填写对方呼号、RSV 和备注。
6. 点击 **添加文字**，再点画布上的文字打开编辑器。
7. 直接拖动文字改变位置；拖动方形手柄缩放，拖动圆形手柄旋转。
8. 设置文字内容、填充色、描边色/粗细、字号和对齐。

文字可以包含：

| 变量 | 发送时替换为 |
| --- | --- |
| `{MYCALL}` | 当前操作员呼号 |
| `{MYGRID}` | 当前操作员 Grid |
| `{HISCALL}` | “对方呼号”输入框 |
| `{RSV}` | RSV 输入框 |
| `{UTC}` | 当前 UTC 时分 |
| `{FREQ}` | 当前 MHz 频率 |
| `{NOTE}` | 备注输入框 |

点击保存图标并填写名称，可保存当前文字布局为个人模板。背景图片按操作员保存，但模板主要保存文字图层；切换操作员后应重新确认背景和模板。

## 选择编码模式

发送区底部的模式下拉框显示模式名称、分辨率和预计时长。常见选择：

- Robot 36：常用、约 320 x 240 的折中选择。
- Martin/Scottie：HF 常见 RGB 系列，不同编号在速度和画质间取舍。
- PD：从 PD50 到 PD290，较高分辨率模式占用更长。
- Wraase/Pasokon：用于与相应设备或软件互通。
- Robot BW：黑白模式，适合较快或特定用途。

以对方能接收的模式为准。预计秒数会显示在发送按钮上，台呼识别和增强前导会略微增加总时长。

## 台呼识别和增强前导

发送区齿轮提供：

- **校准前导**：在 VIS 前发送兼容 QSSTV 的增强校准音，默认开启。
- **FSK-ID**：图片结束后用 FSK 发送当前操作员呼号。
- **CW**：图片结束后用可听 CW 发送呼号。
- **关闭**：不附加台呼识别。

无法编码当前呼号时，发送按钮会被阻止；可改用受支持的台呼或关闭附加识别。关闭附加识别不免除当地法规要求，必要时应以其他方式完成台站识别。

## 发送图片

1. 确认频率空闲、模式和预计时长。
2. 检查画布上最终文字，没有仍未替换的空字段。
3. 点击 **发送 SSTV 图片**。
4. 如果当前正在接收一幅已确认图片，界面会询问是否中断接收；不确定时取消并等待收完。
5. 发射后观察进度、页面红框、Power、SWR 和 ALC。
6. 需要中止时点击发送按钮旁的停止图标，并确认电台回 RX。

开始命令会核对发射前后的频率；频率已经变化时会拒绝，避免把准备好的图片发到错误频道。

## 语音协调和 SSTV QSO 日志

SSTV 工作区底部保留 **语音** PTT，可在发图前后进行语音协调。它与普通语音模式一样需要 HTTPS、麦克风权限和操作员权限。

展开 **SSTV QSO**：

1. 选择操作员并填写对方呼号。
2. 核对默认 `595`，按需填写 QTH、Grid 和备注。
3. 发送完成后记录 QSO。

当前图片发射完成后创建的 QSO 会与该发送历史关联。接收图片不会自动识别对方呼号，仍需人工填写。

## 收发历史

右侧 **收发记录** 可筛选全部、接收或发送：

- 点击缩略图打开大图。
- 下载按钮保存 PNG 到本地。
- 自己的可重发 TX 记录可直接再次发送；重发前仍会核对当前频率和发射占用。
- 删除需要操作权限且不可撤销。
- “发射中断”或“部分接收”会有黄色提示，不应当作完整图像归档。

## 常见问题

### 有声音但不出图

- 确认引擎开启、音频输入正确且没有静噪切断信号。
- 自动模式错过 VIS 时，手动选择已知模式。
- 核对 USB/LSB/FM；错误侧带会使音调关系反转或偏移。
- 降低削波的接收电平。

### 图片倾斜、错色或撕裂

- 检查声卡采样率和系统时钟稳定性。
- 确认模式没有选错。
- 避免蓝牙音频、降噪、AGC 或音效处理改变 SSTV 音调。
- 远程监听播放和服务端解码是两条独立音频链路，应先检查服务器实际输入。

### 电台发射但对方收不到

- 检查发射音频输出、电台 DATA/MIC 输入源和 PTT。
- 查看 ALC；过驱会严重破坏色条和同步。
- 确认侧带、活动频率和发送模式与对方一致。
- 不要用语音压缩或系统“增强音效”处理 SSTV 音频。
