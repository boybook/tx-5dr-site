# 语音通联

语音是正式功能。TX-5DR 可以在网页中完成选频、监听、浏览器麦克风 PTT、语音键控和日志记录；部署在电台旁的 Linux 或 Docker 主机上时，同样不需要远程桌面的音频重定向。

## 能做什么

- 直接编辑每一位频率，或按波段选择语音预设。
- 根据电台实际能力切换 USB、LSB、FM、AM、WFM 等模式。
- 使用 Split，并分别调整 RX、TX 频率。
- 把 FM 中继频差、偏移量、CTCSS 或 DCS 保存在频率预设中，一次切换整组参数。
- 在浏览器中听电台音频，并查看延迟、缓冲和链路状态。
- 把电脑或手机麦克风送到电台，点击或用快捷键切换 PTT。
- 录制 3 到 12 条语音消息，试听、循环发送和设置快捷键。
- 手工记录语音 QSO，并编辑或删除最近记录。

*语音工作区把频率、监听、语音键控、PTT 和通联日志放在同一个浏览器页面中。*

## 发射前检查

1. Profile 已连接，电台控制、接收音频和发射音频设备正确。
2. 已创建带呼号的操作员，并使用具有操作权限的账号。
3. 远程浏览器使用 HTTPS。`localhost` 可以使用浏览器麦克风；局域网或公网 HTTP 通常会被浏览器拦截。
4. 电台模式、滤波、MIC/DATA 输入源与实际接线一致。
5. PTT 方法已经低功率验证，松开后电台能立即回到接收。
6. 检查天线、SWR、功率限制和当地频率规划。

## 选择频率和电台模式

1. 在底部工作模式选择 **语音**。
2. 打开底部 **引擎**。
3. 在左侧预设列表选择频率，或用频率大字上方/下方的箭头逐位调整。也可以选中某一位后直接输入数字。
4. 在频率下方选择 USB、LSB、FM 等电台模式。
5. 确认电台面板的实际频率和模式已经同步，而不是只看网页的乐观显示。

模式按钮来自当前电台报告的能力。某个模式没有出现，表示当前连接没有报告它；不要用相近模式代替后直接发射。

### 保存常用频率

管理员可点击 **添加当前频率为预设**，或打开 **管理语音预设**。预设可以保存：

- 频率、波段和显示名称。
- USB、LSB、FM 等电台模式。
- FM 中继正/负频差和偏移量。
- CTCSS 或 DCS。

以后点一次预设，TX-5DR 会按电台能力写入这组参数。切换后仍应在电台上确认；不支持的中继或亚音能力可能只读或不可用。

### Split

点击频率卡片右上角的 Split 设置：

1. 打开 Split。
2. 等待 TX 行取得电台当前的发射频率。
3. 分别编辑绿色 RX 和红色 TX 数字。
4. 完成 QSO 后关闭 Split，避免下一次通联误用旧 TX 频率。

只有电台和当前连接报告可写 Split 时，TX 行才可编辑。

## 在浏览器中监听

底部 **引擎** 和耳机图标 **音频监听** 是两个开关。

1. 先确认引擎已打开。
2. 点击 **开启监听** 或耳机图标，在弹层底部打开监听开关。
3. 调整“监听音量”。这是当前浏览器的播放音量，不是电台 AF 增益。
4. 正常链路会显示延迟、播放缓冲、Opus/PCM 和当前传输方式。

语音发射时，普通监听会自动静音以避免回授；软件静噪关闭时也可能压低播放。语音键控发射时可保留适合操作的监听行为。

Profile 使用 IF 基带输入时，浏览器语音监听会被禁用。IF 适合频谱/解调，不是可直接收听的 AF 音频。需要语音监听时改用 AF 输入或另设 Profile。

音频链路和公网设置见[远程监听与语音链路](./realtime-audio)。

## 浏览器麦克风 PTT

### 第一次发射

1. 选中正确操作员。
2. 点击右侧红色 **PTT**。首次使用时允许浏览器访问麦克风。
3. 状态先显示“请求中”，取得语音链路和电台占用后变为发射；页面同时出现红色边框。
4. 对着麦克风说话，观察 PTT 旁的输入电平和电台功率。
5. 再点一次 PTT 停止，确认红框消失、电台回 RX。

PTT 是点击切换，不是必须一直按住。手机上同样点击开始、再次点击停止。

### 快捷键

桌面端可从 PTT 按钮右上角选择快捷键：反引号、空格、Home 或 F1 到 F12。按一次开始，再按一次停止。默认使用反引号。

快捷键在输入框中可能被输入组件占用，且浏览器、系统或插件页面也可能抢占功能键。第一次设置后必须在低功率条件下实测。

### 占用状态

语音 PTT 是共享资源。其他客户端或语音键控正在使用时，按钮会显示 **被占用**，不能并发抢占。不要通过刷新页面尝试解除占用；等待当前发送结束，或由发起端停止。

非本机 HTTP 页面会弹出 HTTPS 提示。即使账号有操作权限，浏览器也可能拒绝麦克风。管理员应配置 HTTPS；“不再提示”只隐藏警告，不会改变浏览器安全策略。

## 语音键控

语音键控适合 CQ、台网报到、固定介绍或重复广播。录音按操作员呼号保存。

### 录制消息

1. 展开 **语音键控**，选择操作员。
2. 切到 **编辑**。
3. 选择 3、4、5、6、8、10 或 12 个槽位。
4. 点击某槽的录音按钮，说完后再次点击停止。
5. 使用试听按钮检查内容；不合适可删除并重录。
6. 修改槽名称，并为槽选择 F1 到 F12 快捷键。

不足约半秒的录音不会保存；单条录音最长约 2 分钟。录音也依赖 HTTPS/`localhost` 和浏览器麦克风权限。

### 发射和循环

1. 切回 **发射**。
2. 点击有录音的槽位，或按其功能键。
3. 槽位显示发送进度，页面出现红色发射边框。
4. 再点活动槽，或按 `Esc`，即可停止。

打开槽位的循环开关后，可设置 1 到 300 秒间隔。循环等待期间会显示倒计时；如果 PTT 被占用，会继续等待释放。离开页面前必须关闭循环并确认红框消失。

## 记录语音 QSO

右侧 **语音通联日志** 会使用当前操作员呼号/Grid、当前频率和电台模式。PTT 第一次开始和最后一次结束会帮助填写时间。

1. 填写对方呼号。
2. 核对发送和接收 RST，默认是 `59`。
3. 按需填写 QTH、Grid 和备注。
4. 点击 **记录 QSO**。
5. 在“最近通联”中确认记录；点选记录可编辑，再次保存或删除。

日志表单不会从语音内容中自动识别呼号、姓名或报告。切换操作员后，先确认表单顶部显示的本台呼号，再保存。

## 中继通联

推荐把每个中继保存为一个 FM 预设：

1. 调到中继接收频率并选择 FM。
2. 添加/编辑当前预设。
3. 设置发射频差方向和偏移量。
4. 选择无亚音、CTCSS 或 DCS，并填写对应值。
5. 保存后重新点选该预设，确认电台的 RX、TX 和亚音状态。
6. 低功率短按 PTT，等待中继回波或标识，再开始通联。

预设中的偏移和亚音只在 FM 下使用。电台不支持相应写入时，必须在电台本机设置；网页显示预设内容不等于电台已经接受。

## 电台控制和数值表

语音模式常用的能力包括 RF Power、MIC Gain、压缩、MON、VOX、静噪、AGC、滤波宽度、RIT/XIT、Split、中继频差和亚音。界面只显示当前连接实际提供的项目。

- 语音过小：先看浏览器麦克风电平，再区分 TX-5DR 总增益与电台 MIC Gain。
- 语音失真或 ALC 过高：降低增益/压缩，不要靠降低接收音量掩盖。
- FM 无法打开中继：核对偏移方向、偏移量、CTCSS/DCS 和窄/宽 FM。
- VOX 意外发射：远程 PTT 场景通常关闭 VOX，避免监听回放或系统提示音触发。

## 停止和安全边界

1. 点击 PTT、活动语音槽或 `Esc` 停止当前发送。
2. 确认页面红框消失，电台回到接收。
3. 关闭所有循环语音槽。
4. 不再操作时可关闭浏览器监听；这不会自动关闭服务端引擎。

浏览器无响应、网络中断或电台仍保持 TX 时，应使用电台本机 PTT/发送键解除。远程无人值守站应另备独立的硬件或电源级停发手段。

## 常见问题

### 能听到但不能发射

- 检查当前账号是否为操作员或管理员。
- 使用 HTTPS 或 `localhost`，并允许麦克风。
- 确认已选择带呼号的操作员。
- 查看语音 PTT 是否被其他客户端或语音键控占用。
- 检查 Profile 的发射输出和 PTT 方法。

### 电台发射但对方听不到

- 看麦克风电平是否有变化。
- 检查电台输入源是 MIC、USB 或 DATA 中的哪一个。
- 逐级检查浏览器麦克风、TX-5DR 总增益、电台 MIC/DATA Gain。
- 确认未误用静音的音频输出设备。

### 远程声音断续

先保持编码和缓冲为自动；再查看欠载、抖动和当前链路。可临时切换低延迟 RTC/兼容 WS 判断网络原因，或增加固定缓冲。缓冲越大越稳，但 PTT 对讲延迟也越高。
