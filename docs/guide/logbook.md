# 通联日志

TX-5DR 为每个操作员维护通联日志。正式的 FT8 和实验性的 FT4 在标准通联完成后可以自动写入；语音和实验性的 CW 可以从对应工作区手动记录。日志页支持查询、修改、导入导出、统计、恢复和外部同步。

## 打开日志本

在主界面的操作员卡片中点击 **通联日志**。打开后先确认页面顶部显示的是正确的操作员呼号和日志本。

日志表通常包含：

- UTC 时间
- 对方呼号和 Grid
- 我的呼号和 Grid
- 波段、频率和模式
- 发送与接收报告
- QSL 上传、确认和同步状态
- 备注和 DXCC 信息

## 查找通联

可以按呼号、Grid、波段、模式、DXCC 状态和 QSL 流程筛选。清除筛选后才会重新显示完整日志。

统计区可查看总 QSO、唯一呼号、首次/最近通联以及 DXCC 按波段或模式的分布。地图页会根据日志中的 Grid 显示通联位置；缺少有效 Grid 的记录不会出现在地图上。

## 手动添加或修改

语音、CW 或补录历史记录时：

1. 点击 **添加 QSO**。
2. 填写对方呼号、频率、模式和 UTC 时间。
3. 根据模式填写 Grid、RST 或信号报告。
4. 确认“我的呼号”属于当前操作员。
5. 保存并重新检查表格中的结果。

编辑现有记录时应特别检查频率单位、模式、台站呼号和时间。删除操作无法依靠外部同步自动恢复，删除前先确认记录和操作员。

## 导入 ADIF 或 CSV

点击 **导入** 后选择文件。导入过程会尝试合并已有记录并跳过可识别的重复项。

导入前建议：

- 先导出当前日志作为备份
- 确认 ADIF 中的 `CALL`、时间、波段或频率等关键字段
- CSV 使用导入向导要求的列名
- 大批量导入后抽查多个波段和日期

导入完成提示会分别显示新增、合并和跳过数量。不要只看“成功”两个字就假定所有行都已进入日志。

## 导出

点击 **导出**，选择 ADIF 或 CSV，并决定范围：

- 全部记录
- 指定日期范围
- 当前筛选结果

需要上传 LoTW、迁移到其他日志软件或长期归档时，优先保留 ADIF。CSV 更适合人工检查和表格分析。

## 同步外部服务

TX-5DR 通过内置插件提供日志同步。当前可使用的服务包括：

- WaveLog
- QRZ.com
- LoTW
- Club Log

进入日志页的 **同步设置**，或在 **设置 > 插件** 中打开对应 Provider：

1. 启用需要的同步插件。
2. 在全局设置填写服务地址或账号信息。
3. 在操作员设置中选择对应台站或日志本。
4. 先执行连接测试。
5. 再选择下载、上传或完整同步。

API Key、密码和证书属于敏感信息。不要把配置截图、诊断日志或插件目录打包后公开发布。

LoTW 还需要有效证书和台站位置。自动上传开启前，先用少量 QSO 验证呼号、Grid、DXCC、州/省和证书范围是否匹配。

## 自动记录和同步的边界

- FT8/FT4 是否完成由当前通联机制判断；异常或手动中断的通联不一定自动记录
- 语音和 CW 的日志表单需要操作员确认
- SSTV 历史图片与 QSO 日志是不同对象，只有明确关联后才视为同一通联资料
- WW Digi 竞赛工作台可能维护竞赛专用状态，不能假定所有竞赛导入记录都会进入主日志本
- 外部服务显示“已上传”不等于已经获得双向确认

## 日志健康与恢复

日志页检测到未完成写入、备份或恢复文件时，会显示健康状态和恢复入口：

1. 先停止正在进行的发射和批量同步。
2. 查看当前文件、备份文件和未落盘记录的时间与数量。
3. 在恢复前导出仍可读取的日志。
4. 选择恢复后重新打开日志，抽查最近 QSO。
5. 最后再恢复外部同步。

不要在服务运行时手工覆盖日志文件。需要文件级处理时，先停止 TX-5DR 并保留完整数据目录副本。

## 备份建议

- 定期导出每个操作员的 ADIF
- 同时备份 TX-5DR 数据目录，而不只是导出的表格
- 大批量导入、日志恢复、版本升级前额外做一次备份
- 确认备份包含插件数据，否则同步游标和 Provider 状态可能丢失

各运行形态的数据保留方式见 [部署、升级与备份](./deployment)。
