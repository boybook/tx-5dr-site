# 界面与日常操作

TX-5DR 把接收、通联和电台控制放在同一个网页里。电台旁的主机负责连接硬件和持续运行，操作员可以从电脑、平板或手机打开同一套界面，不必远程控制一整台桌面。

## 三种不同的模式概念

| 层次 | 界面中的例子 | 它控制什么 |
| --- | --- | --- |
| TX-5DR 工作模式 | FT8、语音，以及实验性的 FT4、CW、SSTV、FAX | 使用哪一套接收、发射和日志工具 |
| 电台模式 | USB、USB-DATA、LSB、FM、CW | 电台自身的调制和滤波状态 |
| 通联机制 | 标准通联、辅助队列、WW Digi | FT8/FT4 报文按什么规则推进 |

不要把它们混在一起。例如，选择 **FT8** 是切换 TX-5DR 的数字工作区；Profile 中的 **USB-DATA** 才是要写入电台的模式；选择 **辅助队列** 则只改变 FT8/FT4 的通联流程。

## 桌面端的左右工作区

桌面浏览器通常显示左右两栏，中间分隔线可以拖动。

- 左侧以接收为主：解码列表、频谱/瀑布、频率面板或连续纸带。
- 右侧以操作为主：当前操作员、发射控制、通联日志、预设消息和插件页面。
- 最下方是公共电台控制区：连接状态、Profile、频率、工作模式、引擎和电台能力入口。

不同工作模式会换用适合该任务的界面：

| 工作模式 | 左侧 | 右侧 |
| --- | --- | --- |
| FT8 / FT4（实验） | 全部解码、瀑布、数值表 | 与当前操作员有关的消息、操作员卡片 |
| 语音 | 频率、模式、预设、频谱、数值表 | 最近通联、日志、语音键控、PTT |
| CW | 频率、滤波频谱、解码、发报 | 最近通联和 CW 日志 |
| SSTV | 接收纸带、频率、频谱 | 收发历史、图片编辑和发送 |
| FAX | 接收纸带、频率、频谱 | 仅接收历史 |

## 手机和平板

窄屏设备会把左右栏变成底部页签。数字模式显示 **解码** 和 **呼叫**；图像模式显示 **接收**、**发送**或**收发记录**。

- 在 FT8/FT4 解码页双击一条消息后，界面会自动切到呼叫页。
- 切换页签不会停止服务端的解码或操作员任务。
- 浏览器退到后台或关闭页面，也不等于已经停止服务端发射。离开前应先确认操作员 PTT 已关闭，且页面没有红色发射边框。

## 顶部状态和常用入口

顶部各入口在不同模式中位置略有变化，但含义相同。

| 入口 | 用途 |
| --- | --- |
| 台站信息 | 查看当前台站呼号、名称、QTH 和 Grid |
| 远程访问 | 管理员查看浏览器访问地址和当前客户端数量 |
| UTC 时钟 | 查看 UTC 和校时状态；数字模式应特别留意误差 |
| 服务状态 | 查看 TX-5DR 服务和关键组件是否正常 |
| 通知 | 打开或关闭 QSO 完成通知 |
| 用户 | 查看当前身份、角色，或退出登录 |
| 主题 | 切换浅色、深色或跟随系统 |
| 设置 | 打开操作员、频率预设、插件、系统等设置 |

服务器部署时，多个浏览器看到的是同一台电台和同一组服务端状态。一个客户端改频率、切换 Profile 或启动发射，其他客户端也会看到变化。需要多人共用时，应先配置角色和频率权限，见[操作员、用户与远程访问](./operators-remote)。

## 底部电台控制区

### 连接状态和 Profile

电台名称旁会显示连接、重连或错误状态。点击状态可打开电台控制；管理员可从齿轮入口编辑 Profile。

Profile 是一组“电台连接 + 音频设备”配置。切换 Profile 会改变实际硬件和信号链，不只是换一个界面名称。详细操作见[电台 Profile](./radio-profile)。

### 频率和工作模式

左侧大字下拉框选择预设频率，也可输入自定义频率；右侧下拉框在 FT8、语音、CW、SSTV、FAX 等工作模式之间切换。

切换频率或工作模式会重置正在运行的数字通联状态。发射中不要换频或换模式；先停止操作员，再确认电台回到接收。

### “引擎”不是浏览器监听

底部 **引擎** 开关控制服务端的当前模式引擎：数字模式用它开始解码，语音/CW/图像模式也依赖它建立对应的音频处理。

耳机图标的 **音频监听** 则控制当前浏览器是否播放电台音频。两者相互独立：

- 只开引擎：服务端可以解码或处理音频，但浏览器不一定出声。
- 只开浏览器监听而服务端引擎未就绪：可能没有可播放的音频。
- 远程语音操作通常需要两者都正常。

### 快捷电台能力

连接后的工具栏会按电台实际报告的能力显示入口，例如：

- 电台控制：增益、滤波、AGC、静噪、VOX、Split、中继参数等。
- 发射总增益：调整 TX-5DR 送往电台的音频电平。
- 音频监听：音量、延迟、缓冲、编解码和传输方式。
- 天调：开启内置天调或执行一次调谐。
- 虚拟频差：在 FT8/FT4 中把发射音频保持在电台较合适的通带位置。

没有显示某项控制，通常表示当前连接没有报告该能力、能力仍在检测、或当前用户只有查看权限。完整说明见[电台控制与数值表](./radio-controls)。

## 频谱、瀑布和数值表

频谱来源取决于 Profile 和电台能力，可能是音频频谱、电台 SDR 频谱或 OpenWebRX。来源切换、缩放、主题和周期分割线都在频谱自身的工具栏中。

### 选择来源和视图

1. 有多个来源时，点击频谱工具栏中的 **音频**、**电台 SDR** 或 **OpenWebRX** 选择信号源。
2. 使用放大/缩小按钮调整显示范围；数字模式可切到固定的 5 kHz 视图。
3. 电台 SDR 可选择完整中心视图或左/右半边；OpenWebRX 支持时可切换数字细化视图。
4. 打开频谱设置可选择主题、周期分割线和自动/手动强度范围。

桌面应用中的 **在独立窗口中显示** 会把频谱移到单独窗口，方便放在第二块屏幕。关闭独立窗口后，频谱会回到主界面；这不会停止解码或改变服务端频谱源。

数字模式下，彩色发射标记代表各操作员的音频偏移。连接支持交互频谱时可以拖动标记；音频频谱通常也允许右键把当前操作员移到指定偏移。是否可用以鼠标悬停提示为准。

数值表只显示当前连接实际提供的数据：

- 接收时常见为 Level、S 表或 dBm。
- 发射时常见为 Power、SWR、ALC。
- ALC 进入告警区时应降低总增益或电台数据输入增益，不能把红色告警当作正常满刻度。

## 发射状态和停止

任何模式开始物理发射后，整个页面会出现红色边框。看到红框时，应把它当作“电台正在发射”的最终提示，而不是只看某个按钮的文字。

停止时按以下顺序处理：

1. 在当前模式的发射卡片关闭 PTT、停止消息或停止图片。
2. 数字模式若当前帧仍在空中，打开操作员 PTT 控制并选择 **立即停止发射**。
3. 确认红色边框消失，电台面板回到 RX，功率和 ALC 回落。
4. 页面无响应时，使用电台本机 PTT/发送控制或断开发射音频；不要继续反复点击网页按钮。

## 从 WSJT-X / JTDX 迁移

TX-5DR 沿用熟悉的 FT8 概念，但把状态放在服务端，并允许多个操作员、队列和插件参与。

| WSJT-X / JTDX 习惯 | TX-5DR 中的位置 | 差异 |
| --- | --- | --- |
| Rig、Test CAT、Test PTT | Profile 和连接状态 | Profile 同时保存电台与音频，不包含完整通联流程 |
| Band / 工作频率 | 底部频率选择 | 预设可同时带入电台模式；远程客户端共享同一频率 |
| Mode | 底部工作模式 | FT8 是 TX-5DR 模式；USB-DATA 是电台模式 |
| Band Activity | 左侧全部解码 | 可显示位置、日志分析、队列序号并按 dB/距离排序 |
| Rx Frequency | 右侧相关消息 | 只显示当前操作员、目标和流程相关消息 |
| Tx even / 1st | 操作员卡片的 00/30、15/45 或奇偶周期 | 每个操作员分别设置 |
| Tx 1 到 Tx 6 | 操作员状态选择和展开详情 | 通联机制会自动推进；也允许人工切换和编辑 |
| DX Call / DX Grid | 操作员的目标；Grid 从解码报文补全 | 双击解码行可直接选择目标 |
| Tx audio frequency | 操作员的频率 Hz、瀑布发射标记 | 每个操作员独立，可自动选择空闲位置 |
| Enable Tx / Halt Tx | 操作员 PTT 开关 / 立即停止发射 | 关闭浏览器不等于 Halt Tx |
| Auto Seq | 标准通联或其他通联机制 | 规则由所选机制决定，不是单一全局开关 |
| Call 1st | 自动回应、辅助队列或竞赛候选选择 | 可按新 DXCC、新网格、新呼号、SNR 等规则选择 |
| Fake It | 虚拟频差 | 保持实际空中频点不变，并将发射音频移到约 1500 Hz 附近 |
| Log QSO | 操作员卡片的日志入口 | FT8 完成时自动记录；语音/CW/SSTV 使用表单记录 |
