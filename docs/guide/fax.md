# FAX（实验，仅接收）

::: warning 实验功能
FAX 当前只提供接收、连续纸带、保存、历史和校准，**不能发射 Radiofax**。界面不会提供发送页、PTT 或 FAX QSO 表单。
:::

TX-5DR 可以长期守听海洋气象传真，把信号连续打印成灰度纸带，并在浏览器中修正水平相位和时钟斜率。服务器部署尤其适合持续接收，不需要保持远程桌面会话。

## 能做什么

- 内置东京 JMH、首尔 HLL2、广州 XSQ、美国海岸站、澳大利亚、德国和英国等常见海洋气象传真频率预设。
- 以 USB 拨盘频率进入常见 J3C/F3C/F1C 接收频道。
- 自动识别接收参数，或手工选择 IOC/LPM/调制组合。
- 在传输中途加入，并在弱信号或协议边界之后继续打印连续纸带。
- 保存当前纸带，查看、下载或删除接收历史。
- 自动跟踪或手工调整 Phase 与时钟 ppm。

预设来自公开频率资料，但播发时刻和频道可能变化。收听前应查阅电台最新官方 schedule。

## 频率为什么低 1.9 kHz

海洋传真资料通常公布 **assigned frequency**。使用 USB 和音频解码时，电台拨盘需要调到 assigned frequency 下方约 `1.9 kHz`，让传真中心音落在约 1900 Hz。

TX-5DR 的内置 FAX 预设名称显示官方 assigned frequency 和台站，实际会把电台调到相应的 USB 拨盘频率。选择内置预设时不要再手工减一次 1.9 kHz。

使用自定义频率时，必须自己区分资料中的 assigned frequency 与电台 dial frequency。

## 开始接收

1. 在底部工作模式选择 **FAX**。
2. 从左侧列表选择目标台站和频道，确认电台为 USB。
3. 打开底部 **引擎**。
4. 在接收画面右上角保持 **自动**。
5. 对照官方 schedule，在播发前提前守听。纸带会从当前时刻持续向下增长。
6. 向上翻看时自动跟随会暂停；点击右下角按钮回到最新行。

FAX 不要求从第一页第一行才开始工作。中途调入时也可能逐渐得到内容，但缺少的顶部、APT 或 phasing 不能从空中补回，历史会保留为部分接收。

## 自动和手工接收模式

自动模式会持续评估常见 IOC/LPM 和 FM/AM 组合。已知播发参数、自动识别不稳定或中途加入时，可手工选择：

- `IOC576 · 120 · FM`
- `IOC288 · 120 · FM`
- `IOC576 · 120 · AM`

切换接收模式会重启当前解码器并在连续纸带上形成边界。不要在已经清晰出图时随意切换。

## 连续纸带

FAX 画面不会在每次 APT stop 后清空：

- 新的检测、手工模式、信号中断和恢复会插入分隔标记。
- 旧纸带向上保留，超过保留范围的部分可能被截断并显示提示。
- 右上角模式名和行数用于判断接收仍在推进。

这适合无人值守守听，也意味着“画面里有多张传真”是正常现象。需要归档时，在合适边界后点击保存，而不是等界面自动清空。

## 保存和历史

1. 选择带呼号的操作员。
2. 点击纸带左上角的保存图标 **保存当前纸带**。
3. 打开右侧 **收发记录**；FAX 只显示接收记录。
4. 点击缩略图查看大图，或下载为 PNG。
5. 不需要的记录可删除；删除不可撤销。

保存的是当前可用纸带内容。长时间守听前应定期保存，避免较早行因纸带保留上限而被截断。

## 校正偏移和倾斜

收到 FAX 后，纸带左上角会出现滑杆图标和状态点。

### 自动校正

保持 **自动** 开启。识别到可靠 phasing 后，状态点会转为跟踪/锁定，后续行使用估计的相位和时钟校正。

### 手工校正

- **Phase**：左右平移一行的起点。图像在某一垂直位置断开并左右错位时调整它。
- **ppm**：校正接收时钟。竖线向左或向右倾斜、整幅图逐渐剪切时调整它。
- 重置按钮：撤销该段手工校准。
- 应用按钮：把当前自动开关、Phase 和 ppm 写入当前 FAX 段。

调整顺序：

1. 先用 Phase 把一行的左右拼接位置放到图像边缘。
2. 再小幅调整 ppm，让海岸线、经纬网或文字竖线保持竖直。
3. 每次只改一个方向并观察较长一段，不要用巨大 ppm 值掩盖错误模式。
4. 校正满意后再保存纸带。

## 常见问题

### 只有噪点，没有天气图

- 核对官方 schedule、UTC、台站和当天使用频道。
- 确认内置预设已经处理 1.9 kHz，不要重复偏移。
- 检查 USB、滤波宽度和接收音频；关闭静噪和语音降噪。
- 自动模式长期不稳定时，根据台站资料手工选择 IOC/LPM/调制。

### 图像左右重复或断开

优先调整 Phase。若断点位置随时间持续移动，再调整 ppm。完全错误的重复宽度通常是 IOC 选错，不应靠 Phase 修复。

### 图像持续倾斜

确认 LPM 正确，再使用自动时钟恢复或小幅 ppm 校正。声卡重采样、蓝牙设备和系统音效会增加漂移，建议使用稳定的有线音频设备。

### 历史里只有部分图

可能是中途加入、信号丢失、手工切模式或纸带早期内容已截断。黄色“部分接收”是事实标记；保存和下载不会把缺失行补齐。
