# CW（实验）

::: warning 实验功能
CW 发报、解码和界面仍可能调整。不要把实验性解码结果直接用于自动发射；首次连接任何键控接口时，必须使用假负载或低功率并准备从电台本机停发。
:::

TX-5DR 的 CW 工作区可以用电台 CAT 文本发报，也可以用独立串口的 DTR/RTS 驱动电键接口；同时提供文字输入、预设报文、Web 侧音、实验性解码和 CW 日志。

## 两种键控方式

| 方式 | 适合设备 | 前置条件 |
| --- | --- | --- |
| 电台发报（CAT） | 支持整段 CW 文本命令的现代电台 | Hamlib 串口/网络、ICOM WLAN 或 TCI 连接；电台必须实际报告发报能力 |
| 电键接口（串口） | 通过 key jack 键控的电台/接口 | TX-5DR 主机上的独立串口、DTR 或 RTS、正确有效电平和隔离电路 |

CAT 能调频或切模式，不代表一定支持 CW 文本发送。界面显示“CAT CW 当前不可用”时，应改用电键接口或核对电台/Hamlib 的 SEND_MORSE、ICOM CI-V CW 支持。

串口键控端口属于运行 TX-5DR 的主机，不是打开网页的电脑。远程服务器部署时，USB 串口必须插在服务器一侧。

## 配置串口电键接口

1. 打开当前 Profile 的电台设置。
2. 在 **CW 键控端口** 选择或填写独立串口路径。
3. 选择 DTR 或 RTS。
4. 保持默认“高电平按下”，除非接口明确要求低电平反相。
5. 确认电台菜单已把对应接口设为 CW key，并配置合适的 Break-In。
6. 先连接假负载或把功率降到最低，再执行端口测试。
7. 测试结束后确认线路释放，电台回 RX。

不要把已经用于 CAT 或 PTT 的同一控制线随意复用为 CW key。使用晶体管/光耦等合适接口，不要把 RS-232 电平直接接入电键端子。

## 进入 CW 工作区

1. 在底部模式选择 **CW**。
2. 打开 **引擎**。
3. 用左侧频率数字逐位调整；需要异频时从右上角打开 Split。
4. 确认电台实际进入 CW 模式、滤波宽度和 Break-In 状态正确。
5. 在 **CW 发报** 顶部选择“电台发报”或“电键接口”。

左侧还会显示频谱、数值表、CW 解码和发报面板；右侧保存最近通联和日志表单。

## 发送临时文字

### 普通输入

1. 关闭 **实时输入**。
2. 设置 WPM，当前范围 5 到 60。
3. 在输入框填写报文。
4. 按 Enter 或点击 **发送**。
5. 发送中点击 **停止**；页面红框消失后才算回到接收。

### 实时输入

打开 **实时输入** 后，每个键入字符会立即排入发射队列。它适合熟练的键盘 CW 操作，但有两个重要区别：

- 已经排入的字符不能像普通编辑器那样可靠撤回。
- 网络、CAT 电台缓冲和串口时序会影响实际发送节奏。

先用普通输入验证键控和 WPM，再启用实时输入。粘贴长文本前先确认内容；需要停止时立即点 **停止** 或按 `Esc`。

Web 侧音只在当前浏览器播放，方便预听节奏，不是电台实际 RF 音调。可单独调整开关、音调和音量。

## 占位符和预设报文

预设报文按操作员呼号保存，可使用：

| 占位符 | 取值来源 |
| --- | --- |
| `{MYCALL}` | 当前操作员呼号 |
| `{HISCALL}` | CW 日志表单中的对方呼号 |
| `{TRST}` | 日志表单中的发送 RST |
| `{RRST}` | 日志表单中的接收 RST |

### 编辑预设

1. 切到 **编辑**。
2. 使用加减按钮把槽位数设为 3 到 12。
3. 填写标签、报文、循环开关和 1 到 300 秒间隔。
4. 为槽位选择 F1 到 F12；同一呼号下，一个快捷键只分配给一个槽。
5. 可拖动槽位调整顺序，或删除不再使用的槽。

### 发射预设

1. 在右侧日志表单先填对方呼号和 RST，确保占位符有值。
2. 切回 **发射**。
3. 点击槽位或按对应功能键。
4. 检查展开后的实际文本和预计时长。
5. 再点活动槽、点 **停止** 或按 `Esc` 结束。

占位符缺值时界面会拒绝发送并指出缺少项目。循环 CQ 属于真实自动发射，离开页面前必须关闭循环。

## CW 解码

CW 解码器根据接收音频做连续转写，结果仅作操作辅助。

1. 在 **CW 解码** 打开开关。
2. 等待状态从启动中变为运行/监听。
3. 频谱上出现 CW 滤波框后，拖动它对准目标音调；拖动边缘调整宽度。
4. 也可从解码卡片选择 100、150、250、500 或 800 Hz 滤波宽度。
5. 灰色文字是尚未稳定的候选，正常文字是已经确认的片段。
6. 解码到呼号后，点击“使用呼号”图标把它带入 CW 日志表单。
7. 点 **清空** 只清除当前转写，不删除 QSO 日志。

目标音调可在约 100 到 1500 Hz 内调整。窄滤波可减少邻台干扰，但调偏后会丢字；宽滤波更容易包含目标，也更容易混入其他信号。

解码设置可选择可用模型和 CPU/CoreML/CUDA 等运行后端。列表以当前安装实际显示为准；后端“不可用”通常表示模型或运行时缺失，不代表电台连接故障。

自动解码无法替代耳听。弱信号、QRN、多人重叠、非标准间隔和速度变化都可能产生看似合理的错误文字。

## 记录 CW QSO

右侧 **CW 通联日志** 默认使用 `599`，并从当前操作员、频率和 CW 发报状态取得基础信息。

1. 填写对方呼号、发送/接收 RST。
2. 按需填写 QTH、Grid 和备注。
3. 点击 **记录 QSO**。
4. 在最近通联中选择记录，可编辑或删除。

使用 TX-5DR 发报时，开始/结束时间会随键控状态填写。使用外接手键或另一台键控器时，TX-5DR 不一定知道真实起止时间，应在保存前人工核对。

## 停止和安全边界

1. 点 **停止** 或按 `Esc` 停止文字/预设发报。
2. 关闭所有循环槽。
3. 确认页面红框消失、电台回 RX。
4. 串口掉线后如果电台仍发射，立即在电台本机解除 Break-In/PTT，并断开电键接口。

网页关闭、网络断开或解码器停止都不构成可靠的硬件释放保证。串口电键接口应设计成掉电释放，并准备独立停发手段。

## 常见问题

### CAT 可控频率，但不能发报

这通常表示电台不支持当前连接的 CW 文本命令。查看界面提示，核对 Hamlib SEND_MORSE、CI-V 或 TCI 能力；无法确认时改用隔离的电键接口。

### 串口键控没有反应

- 确认选的是独立 CW key 端口，不是 CAT 端口。
- 检查 DTR/RTS 和有效电平。
- 确认端口未被其他程序占用。
- 检查电台 Break-In、key jack 和接口接线。

### 字间隔或速度不正确

串口方式由 TX-5DR 按 WPM 生成时序；CAT 方式还受电台内部键控设置影响。先发送短测试词，对比电台侧速度，再调整；不要一开始就用长循环报文测试。
