# 搭好第一套站台

第一次配置的目标不是马上呼叫 CQ，而是依次证明四件事：电台控制能连通、PTT 能可靠收发切换、接收音频和时钟可用、低功率发射时没有过驱或异常驻波。

下面以“桌面版、单操作员、FT8”为例。服务器版的步骤相同，但串口和声卡应连接在运行 TX-5DR 服务端的设备上，而不是打开网页的电脑上。

完成以下硬件和发射安全检查后，再开始真实通联。

## 开始前先处理发射安全

准备好这些条件后再测试 PTT：

- 电台已经连接可靠的天线系统或额定功率足够的假负载；
- 外接功放关闭或置于旁路；
- 电台 RF 输出功率已调到较低值；
- 已确认当前频率可以进行短时测试，不会干扰正在进行的通联；
- WSJT-X、JTDX、日志软件等没有同时占用同一个 CAT 串口或声卡；
- 能随时在电台面板断开发射，并知道 TX-5DR 中“立即停止发射”的位置。

::: danger PTT 测试会让电台真实进入发射状态
“测试 PTT”会切换到发射约 0.5 秒。它不会发送 FT8 报文，但也不是模拟按钮。未连接天线或假负载时不要执行。
:::

## 1. 创建电台配置 Profile

没有任何 Profile 时，TX-5DR 会自动打开首次配置向导。已经进入主界面时，点击左上电台栏旁的齿轮按钮 **电台配置**，再选择 **新建电台配置**。

先选连接方式：

| 你的站台 | 在向导中选择 | 最少需要准备 |
| --- | --- | --- |
| USB/串口 CAT，或 Hamlib 支持的设备端点 | **Hamlib 直连电台** | 电台型号、串口或设备地址 |
| 已经运行 rigctld | **Rigctld 服务器** | rigctld 主机和端口 |
| 支持网络遥控的 ICOM 电台 | **ICOM WLAN** | 电台 IP、端口、用户名和密码 |
| SunSDR、ExpertSDR 或兼容 TCI 的软件 | **TCI / SunSDR** | TCI 主机、端口、接收机/TRX/VFO |
| 目前只接收、不控制和发射 | **纯监听** | 接收音频输入设备 |

不确定该选哪一种时，先看[电台兼容性与连接方式](./radio-compatibility)。

## 2. 先通过“测试连接”

在电台配置页填好连接参数，点击 **测试连接**。成功提示应为“连接测试成功！电台响应正常。”

不同连接方式还要检查：

- **Hamlib 直连电台**：型号必须选对。优先从下拉列表选择实际串口；只有电台手册要求时才改波特率、握手、RTS/DTR 等高级参数。
- **Rigctld 服务器**：确认 TX-5DR 所在设备可以访问对应主机和端口，且 rigctld 已经独占并成功连接物理电台。
- **ICOM WLAN**：确认电台与 TX-5DR 服务端网络互通，遥控用户未被其他客户端占用。
- **TCI / SunSDR**：ExpertSDR 常用 40001，Thetis/AetherSDR 常用 50001；不确定时保留方言自动识别和常见端口探测。

连接测试失败时，先解决这个问题，不要继续 PTT。最常见的原因是型号或端口选错、串口被 WSJT-X/JTDX 占用、网络端口不可达、ICOM 账号被占用，或 TCI 服务尚未开启。

## 3. 单独测试 PTT

连接测试成功后，保持功放关闭和低功率设置，点击 **测试 PTT**，同时观察电台：

1. 电台应进入 TX 约 0.5 秒；
2. 随后必须自行回到 RX；
3. TX-5DR 应显示 PTT 测试成功；
4. 若电台没有及时回到 RX，立即从电台面板停止发射并检查配置。

Hamlib 直连和 Rigctld 可以选择以下 PTT 方法：

- **CAT 命令（推荐）**：适合多数现代电台；
- **VOX 声控**：由发射音频触发，界面不会提供 PTT 测试；
- **DTR/RTS 引脚**：用于部分老式电台、接口盒或外部切换电路，可另选 PTT 串口。

ICOM WLAN 通过对应的网络控制链路切换 PTT，TCI 则通过 TCI 会话切换。一次 PTT 测试只证明“能够按下并松开 PTT”，不能证明发射音频、功率、SWR 或 ALC 正常。

## 4. 选择 RX/TX 音频设备

进入向导的 **配置音频设备**：

- **音频输入设备**是电台到 TX-5DR 的 RX 音频；
- **音频输出设备**是 TX-5DR 到电台的 TX 音频；
- 使用普通 USB 声卡时，优先选择带电台或接口名称的设备，不要依赖含义不明的“默认设备”；
- ICOM WLAN 默认选择 **ICOM WLAN**，TCI 默认选择 **TCI Audio**，二者的网络音频不需要另接 USB 声卡；
- 如果电台只接一个声道，在 **输出声道** 中选与接口接线相符的左声道、右声道或单声道。

向导会根据部分电台型号尝试匹配 USB 音频设备，但仍需通过实际接收和发射验证。保存 Profile 后，在 Profile 列表中选中它并点击 **应用**；当前 Profile 则会显示 **重新连接电台**。

![Profile 音频设置中分别选择 RX 输入设备和 TX 输出设备](/guide/screenshots/annotated/profile-audio.png)

*输入设备接收电台音频，输出设备向电台发送调制音频。两者需要分别确认。*

## 5. 验证接收与解码

回到主界面，在模式中选择正式支持的 **FT8**，打开右侧 **引擎** 开关，然后按以下顺序观察：

1. 频谱或瀑布上出现连续的噪声底，而不是完全空白；
2. 调整电台音量或接口电平时，噪声底会跟随变化；
3. 在有 FT8 活动的标准频率上，每 15 秒出现对应时隙的信号；
4. 左侧解码表出现呼号、报告和时间。

只有瀑布、没有解码时，先核对电台是否使用 USB/USB-DATA、滤波器是否足够宽、AGC/降噪是否影响数字信号，以及系统时间是否准确。只有一条直线或严重削顶时，降低接收电平。

::: tip 浏览器里的“音频监听”不是解码开关
**引擎**控制接收和解码；工具栏里的**音频监听**只是把服务端收到的 RX 音频播放到当前浏览器。远程使用时，可以只开引擎而不开本地扬声器监听。
:::

## 6. 检查 UTC 和 NTP 校准

FT8 的时隙依赖准确时间。主界面右上角显示 UTC 时间，旁边的小圆点表示校准状态。管理员点击时间即可打开 **时钟校准**：

1. 点击 **测量**，查看 **NTP 测量偏移**；
2. 开启 **自动应用 NTP 偏移**，或确认测量结果后点击 **应用 NTP**；
3. 等待状态变为 **NTP 已同步**；
4. 如果服务端不能访问 NTP，可在确认真实偏差后填写 **手动偏移**。

TX-5DR 的校准作用于数字模式时隙，不会替你修改操作系统时钟。服务器部署时，应同时让宿主系统保持正常的 NTP/chrony 同步。

![时钟校准面板，显示 NTP 偏移、自动应用、测量和手动应用](/guide/screenshots/annotated/clock-calibration.png)

*先查看测量偏移；通常开启自动应用即可，手动偏移只用于已经确认的特殊情况。*

## 7. 做一次可控的低功率音频测试

接收和时间都正常后，再验证完整 TX 音频链路：

1. 再次确认假负载或天线、频率空闲、功放旁路；
2. 点击左上电台名称旁的滑杆按钮 **电台控制**，把 **发射功率**调到较低值；如果该项没有出现，就在电台面板设置；
3. 点击扬声器按钮 **发射音量增益**，从较低增益开始；
4. 打开塔形按钮 **天调控制**，在“外接天调”区域点击 **手动单音调谐**；
5. 观察主界面的 **Power、SWR、ALC**，两三秒内再次点击按钮停止单音；
6. 确认 PTT 已释放，数值表随后回到接收状态。

这个单音用于检查从 TX-5DR 到电台的音频、PTT 和数值表，不等同于电台内置天调的“手动调谐”。按钮会持续发射到你再次点击，测试时不要离开页面。

### 怎样调整

- **没有 Power，ALC 也不动**：检查音频输出设备、电台 DATA/MOD 输入来源、输出声道和接口电平；
- **ALC 红色告警或自动弹出“ALC 过高”**：立即降低 **发射音量增益**，不要靠降低 RF 功率掩盖音频过驱；
- **SWR 异常**：立即停止，检查天线、馈线、频段和天调；
- **Power 正常但 ALC 读数不提供**：可能是当前电台或控制后端没有暴露 ALC，按电台自身仪表和说明书调整；
- **所有发射数值都不显示**：不一定代表没有 RF 输出，只能说明当前连接没有提供这些遥测数据。

不同电台的 ALC 推荐范围不完全相同，应以电台说明书为准。TX-5DR 的告警用于阻止明显过驱，不能替代台站的功率表、驻波表或假负载。

## 8. 填写站台和操作员

硬件链路通过后，再完成身份配置：

1. 打开 **设置 → 电台信息**，填写电台呼号、名称、Maidenhead 格点和站台简介；
2. 打开 **设置 → 操作员**，创建用于 FT8 通联的操作员，核对呼号、网格和并行通联流数；
3. 回到主界面，在操作员卡片中确认呼号、网格和发射周期；
4. 第一次真实通联前保持自动起呼关闭，从手动选择一条解码开始。

Profile、站台信息、操作员和登录用户不是同一个对象，详细区别见[电台 Profile 与音频](./radio-profile)。CAT、PTT、音频和发射指标全部验证通过后，才启用自动发射。
