# 第一次 FT8 通联

以下操作使用桌面版、一个操作员和一部常见的 USB 电台。完成后，你应该能看到 FT8 瀑布图与解码，知道如何安全开始和立即停止发射，并能在日志本中找到通联记录。

预计用时取决于电台驱动、CAT 和声卡是否已经可用。不要为了赶时间跳过 PTT、时钟和低功率检查。

::: info 硬件验收
电台尚未完成 CAT、PTT、RX/TX 音频和 ALC 验收时，请先按[搭好第一套站台](./first-steps)逐项测试。
:::

## 开始前准备

- Windows、macOS 或带图形界面的 Linux 电脑
- 已正确连接天线或假负载的电台
- CAT 连接和收发音频链路
- 你的呼号和 Maidenhead Grid
- 正确同步到 UTC 的系统时钟

::: warning 第一次发射
先降低电台功率，并确认当前频率可用。不要在未连接天线或假负载时测试 PTT、Tune 或发射。
:::

## 1. 安装桌面版

从官网首页下载与当前系统匹配的桌面安装包。不同包类型和系统要求见 [桌面版安装](./desktop)。

启动 TX-5DR 后，桌面窗口会打开同一套 Web 界面。以后即使迁移到 Linux 服务器、Docker 或 Android，主要操作方式也保持一致。

## 2. 创建第一个电台 Profile

首次进入时，管理员会看到电台配置向导：

1. 选择连接方式。普通 USB CAT 电台通常选择 **Hamlib 直连电台**。
2. 选择电台厂商、型号和串口。
3. 点击 **测试连接**，确认电台能响应频率和模式读取。
4. 选择 PTT 方法，然后点击 **测试 PTT**。
5. 选择接收音频输入和发射音频输出。
6. 给 Profile 起一个能识别硬件的名称，例如 `IC-7300 USB`。

![新建 Profile 时选择连接方式、机型和串口，并测试连接与 PTT](/guide/screenshots/annotated/profile-radio.png)

*选择连接方式和电台型号后，先测试连接，再测试 PTT。*

如果你使用 Rigctld、ICOM WLAN 或 TCI，请先查看 [电台兼容性](./radio-compatibility)。

## 3. 创建操作员

进入 **设置 > 操作员**，创建第一个操作员：

1. 填写你的呼号。
2. 填写 4、6 或 8 位 Grid。
3. 初次使用保持单路并行通联。
4. 保存后，在主界面确认该操作员已被选中。

![新建操作员时填写呼号、Grid 和并行通联上限](/guide/screenshots/annotated/operator-create.png)

*新建操作员只需要填写通联身份和并行通联上限，硬件连接保存在 Profile 中。*

`Profile` 保存硬件与音频配置；操作员保存实际参与通联的呼号和通联设置。切换 Profile 不会替你切换操作员呼号。

## 4. 检查时钟

FT8 对 UTC 时钟敏感。查看界面顶部的 UTC 时间和时钟状态：

1. 优先让操作系统通过 NTP 自动校时。
2. 如果界面提示偏差或同步失败，先修正时钟再继续。
3. 不要使用发射时序补偿来掩盖明显的系统时间错误。

## 5. 接收第一批 FT8

在底部电台控制区：

1. 将通联模式选为 **FT8**。
2. 选择当前波段的 FT8 预设频率。
3. 确认电台处于 USB 或 USB-DATA，并使用较宽的接收带宽。
4. 启动引擎。
5. 等待一个或两个 15 秒周期。

成功时会看到：

- 瀑布图出现信号轨迹
- 左侧解码列表出现呼号、信号报告和消息
- 电台状态保持已连接
- 时钟没有明显告警

没有频谱或解码时，先查看 [按现象排障](./troubleshooting#没有瀑布图或-ft8-解码)。

## 6. 检查发射链路

在真正呼叫前：

1. 再次确认天线、波段和电台功率。
2. 确认发射音频输出指向电台的正确声卡通道。
3. 观察电台控制区和数值表是否能显示发射功率、SWR 或 ALC。
4. 如果需要持续音调测试，使用天调或 Tune 功能，并准备立即停止。
5. 调整总发射增益，避免 ALC 过高或音频过驱。

不同电台只会显示其实际支持的数值和控制项，详见 [电台控制与数值表](./radio-controls)。

## 7. 完成第一次 QSO

最直接的操作方式是响应一个正在呼叫 CQ 的电台：

1. 确认当前选中的操作员和发射奇偶周期。
2. 在左侧解码列表中双击目标 CQ。
3. 检查操作员卡片中的目标呼号、发射频率和待发送消息。
4. 确认没有选择错误的操作员或错误呼号。
5. 开启该操作员的发射。
6. 观察 TX1 至 TX5 的标准交换过程。

需要立即停发时，使用操作员卡片上的 **立即停止发射**，不要等待当前策略自行结束。

标准通联完成后，TX-5DR 会回到 CQ/待机状态，并将 QSO 写入该操作员的日志本。自动回复、连续 CQ、队列和并行通联请在熟悉基本过程后再启用。

## 8. 检查日志

在操作员卡片中打开 **通联日志**，确认：

- 对方呼号和 Grid 正确
- 波段、频率与模式正确
- 发送和接收报告合理
- 开始与结束时间使用 UTC

日志导入、导出和外部同步见[通联日志](./logbook)。
