# 在桌面电脑上安装 TX-5DR

桌面版是完成第一次 FT8 通联的推荐方式。应用中已经包含 TX-5DR 服务和 Web 界面，安装后无需另外部署服务器。

## 适用场景

- Windows、macOS 或带图形桌面的 Linux 电脑就在电台旁
- 使用 USB 串口、USB 声卡或电脑可访问的网络电台
- 希望先用应用窗口完成配置，以后再决定是否开放浏览器访问

## 1. 下载正确的安装包

打开[桌面版 nightly 发布页](https://github.com/boybook/tx-5dr/releases/tag/nightly-app)，按系统和处理器架构选择文件。

| 系统 | 推荐文件 | 其他选择 |
| --- | --- | --- |
| Windows x64 | NSIS `.exe` 安装包 | `.7z` / `.zip` 便携压缩包 |
| macOS Apple Silicon | `macos-arm64.dmg` | arm64 `.zip` |
| macOS Intel | `macos-x64.dmg` | x64 `.zip` |
| Linux x64 / arm64 | `.deb` 或 `.rpm` | `.AppImage` / `.zip` |

不确定 Mac 架构时，打开“关于本机”：M 系列芯片选择 arm64，Intel 处理器选择 x64。

## 2. 安装并首次启动

### Windows

1. 运行下载的 `.exe`。
2. 按安装向导完成安装，然后从开始菜单启动 TX-5DR。
3. 如果使用便携压缩包，先完整解压，再运行其中的 TX-5DR；不要直接在压缩包预览窗口中启动。

### macOS

1. 打开 `.dmg`，把 TX-5DR 拖入“应用程序”。
2. 从“应用程序”启动 TX-5DR。
3. 系统询问麦克风、网络或可移动设备权限时，只为实际需要的功能授权。权限被拒绝后，可在“系统设置 > 隐私与安全性”中重新允许。

### Linux 桌面

- Debian / Ubuntu 使用 `.deb`。
- Fedora / RHEL 系使用 `.rpm`。
- 不希望安装系统软件包时，可给 `.AppImage` 执行权限后直接运行。

Linux 用户还需要确认当前账户能够访问音频设备和串口设备。常见发行版使用 `audio`、`dialout` 等用户组；修改组成员后通常需要重新登录。

## 3. 判断启动是否成功

应用窗口出现 TX-5DR 登录页或主界面，即表示桌面宿主和内置服务都已启动。接下来创建第一个 Profile，并验证：

1. 电台连接状态变为已连接。
2. TX-5DR 能读取当前频率和模式。
3. 音频输入电平随接收信号变化。
4. FT8 页面能够按周期出现解码结果。

具体配置步骤见[第一次 FT8 通联](./quick-start)。在确认接收、频率读取和发射功率设置前，不要启用自动发射。

## 从另一台设备打开桌面版

桌面版运行时，也可以像服务器一样把 Web 界面提供给浏览器。远端看到的是 TX-5DR 自适应网页，而不是这台电脑的远程桌面：不需要传输整个屏幕，也不需要把鼠标、系统音频和桌面会话一起转发。

1. 在 TX-5DR 打开“系统设置 > 访问范围”。
2. 同一网络内使用时，选择“局域网共享”并保存。
3. 使用界面显示的局域网地址，在另一台电脑、平板或手机中打开。
4. 用管理员或操作员令牌登录。

桌面应用必须保持运行，电脑也不能休眠。选择“纯本地使用”后，其他设备将无法连接。

需要通过私有组网、域名或反向代理长期访问时，选择“正式开放部署”，并填写浏览器实际使用的完整地址。公网入口的安全配置见[长期运行、远程访问与升级](./deployment)。如果这台电脑需要长期无人值守，Linux 服务器版通常更容易维护。

## 浏览器音频与语音

本机应用窗口通常不需要额外网络配置。其他设备通过浏览器监听或进行语音通联时，应优先使用 HTTPS，并确保浏览器有麦克风权限。

如果网页和电台控制正常，但远程监听或语音不正常，不要反复重装桌面版。按[远程监听与语音链路](./realtime-audio)检查访问方式、防火墙和兼容传输。

## 常见问题

### 看不到串口或音频设备

1. 在操作系统中确认设备已经被识别。
2. 关闭可能独占 CAT 串口或声卡的 WSJT-X、JTDX、数字接口工具和其他电台软件。
3. 检查 TX-5DR 的系统权限，然后重新打开设备列表。
4. 拔插 USB 设备后仍无效时，完整退出并重新启动 TX-5DR。

### 局域网浏览器打不开

确认桌面应用仍在运行、访问范围为“局域网共享”，并允许 TX-5DR 通过系统防火墙。不要把 `localhost` 或 `127.0.0.1` 发给另一台设备；应使用界面显示的局域网地址。

### 网页能打开但无法控制电台

先确认登录令牌对应的角色具有操作权限。观察者可以查看状态，但不能改变频率、PTT 或发起通联。

## 更新桌面版

更新前结束正在进行的通联并关闭发射。管理员可在 **设置 > 关于** 检查更新；受支持的安装方式可以在应用内下载，并在确认后重启安装。便携包或当前平台不支持自动安装时，界面会引导到官网下载同平台、同架构的新版本。更新后至少重新确认一次电台连接、音频输入、PTT 和时钟状态。

迁移、备份和长期远程值守见[长期运行、远程访问与升级](./deployment)。
